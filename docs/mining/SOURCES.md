# Mining Sources

## How to add a source

1. Drop the file (PDF, EPUB, text) or paste the link into this folder's inbox:
   `docs/mining/inbox/`
2. Extract every testable claim into `CLAIMS.md` with its context
   (how/where/when) and mark it `untested`.
3. Commission the backtest. The claim moves when the numbers speak.

I read PDFs natively — send them and I'll extract the claims.
